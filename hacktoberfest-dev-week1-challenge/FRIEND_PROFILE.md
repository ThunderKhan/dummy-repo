# EntryZero — Friend Profile

## Purpose

EntryZero must be grounded in one real person. This document captures the actual user context that determines the MVP rather than inventing a generic persona.

## Privacy rule

Only store details the friend has agreed can be kept in the repository. Use a pseudonym and anonymized business details when appropriate.

Do not publish customer names, phone numbers, addresses, invoices, credentials, private financial records, or other personal information that is not necessary for the project.

## Why the task is worth automating

- frequency;
- repetition;
- number of fields;
- application switching;
- manual arithmetic;
- copy/paste burden;
- error-prone steps;
- rework.

Do not infer importance from the existence of AI capabilities.

## Trust boundary

- What may EntryZero do without asking?
- What must always require approval?
- What actions are never acceptable?
- What information must never leave the device?
- What would make the friend stop using it?

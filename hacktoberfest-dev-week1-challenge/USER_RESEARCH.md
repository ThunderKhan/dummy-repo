# EntryZero — User Research

## Research question

The question is not:

> "Would a small-business owner like an AI agent?"

It is:

> **Does this specific friend have a recurring workflow where controlled local automation removes meaningful manual work without creating unacceptable trust or verification costs?**

## Method

1. Observe the friend performing the task.
2. Ask them to explain what they are doing.
3. Capture the exact input formats.
4. Capture the exact fields entered.
5. Identify error and rework points.
6. Show the proposed workflow.
7. Test the prototype with the friend.

Prefer neutral questions:

- "Show me the last time you did this."
- "What happens next?"
- "Which part takes the most effort?"
- "What do you double-check?"
- "What happens when a number is wrong?"
- "What would make you refuse to let a program do this?"

Avoid leading questions such as:

- "Would an AI agent save you time?"
- "Would you like this feature?"

## Research integrity

A small sample can establish a real user's experience but not market-wide prevalence.

Valid:

> "My friend performs this task repeatedly."

Not automatically valid:

> "Small businesses lose millions of hours to this."

Broader claims require separate evidence.
